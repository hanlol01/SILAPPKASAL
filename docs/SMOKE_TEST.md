# UX-01

Kasus smoke test manual untuk dieksekusi oleh Product Owner. Test ini hanya dibuat sebagai panduan; QA tidak mengeksekusinya.

| ID Test | Peran | Halaman | Fitur | Input | Langkah | Hasil yang Diharapkan | Prioritas |
|---|---|---|---|---|---|---|---|
| UX01-ST-001 | Pengguna publik | `/register` | Validasi form registrasi pelapor | Form kosong | Buka `/register`; kirim form tanpa mengisi field wajib. | Field wajib menampilkan pesan validasi inline di bawah field terkait; request tidak dikirim. | Tinggi |
| UX01-ST-002 | Pengguna publik | `/register` | Payload sukses registrasi pelapor | Nama, NIM, email, nomor telepon, universitas, program studi, password, dan konfirmasi password yang valid | Isi semua field wajib; kirim registrasi. | Registrasi berhasil; kartu sukses menampilkan nomor registrasi; tidak ada regresi payload atau navigasi yang tidak diharapkan. | Tinggi |
| UX01-ST-003 | Pengguna dengan registrasi ditolak | `/registration/correction` | Validasi koreksi registrasi dan error server | Sesi registrasi rejected yang sudah ada; field koreksi tidak valid atau tidak lengkap | Buka halaman koreksi; kirim dengan field wajib yang kosong; lalu kirim dengan field yang ditolak backend jika tersedia. | Error client tampil inline; error backend 422 tampil di bawah field yang sesuai; alasan penolakan tetap terlihat. | Tinggi |
| UX01-ST-004 | Pengguna publik | `/track` | Validasi format tracking code | `ABC` | Buka `/track`; masukkan tracking code tidak valid; kirim. | Error format tracking code tampil inline; lookup API tidak dikirim untuk format yang tidak valid. | Tinggi |
| UX01-ST-005 | Pengguna publik | `/track` | Penanganan error lookup tracking code | Tracking code dengan format valid tetapi tidak ditemukan | Masukkan tracking code berformat valid yang tidak ada; kirim. | Field tracking menampilkan error server inline; halaman tetap stabil dan dapat digunakan. | Sedang |
| UX01-ST-006 | Admin atau Super Admin | `/dashboard/users` | Validasi form Create Reporter | Form Create Reporter kosong | Buka halaman Users; tampilkan form Create Reporter; kirim form kosong. | Error field wajib tampil inline; reporter tidak dibuat. | Tinggi |
| UX01-ST-007 | Admin atau Super Admin | `/dashboard/users` | Payload sukses Create Reporter | Data reporter valid dengan kampus, program studi, dan password | Isi form Create Reporter; kirim. | Reporter berhasil dibuat; panel temporary password muncul; daftar user diperbarui; tidak ada regresi kontrak payload. | Tinggi |
| UX01-ST-008 | Admin atau Super Admin | `/dashboard/users` | Filter reporter dengan shadcn Select | Filter status aktif, universitas, fakultas, dan program studi | Gunakan setiap filter dengan keyboard dan mouse. | Filter tetap dapat digunakan, konsisten secara visual, dapat dinavigasi dengan keyboard, dan memperbarui daftar tanpa tampilan native select. | Sedang |
| UX01-ST-009 | Pengguna publik | `/register`, `/track` | Lokalisasi pesan validasi | Bahasa aplikasi/browser diatur ke Bahasa Indonesia | Picu error validasi client-side di kedua halaman. | Pesan validasi mudah dipahami dan terlokalisasi; tidak ada teks zod default atau bahasa Inggris yang tidak diharapkan. | Sedang |
