# SILAPPKASAL End-to-End Functional Test Plan

Dokumen ini berisi rencana pengujian fungsional end-to-end untuk SILAPPKASAL setelah UX Sprint dan Frontend Polish sampai UX-09B. Test ini disusun untuk eksekusi manual oleh QA/Product Owner dan tidak menjalankan atau mengubah implementasi.

## Assumptions

- Environment frontend dan backend sudah berjalan dengan data master minimal: universitas, fakultas, program studi, jenis laporan, tipe lokasi, dan user role.
- Akun test tersedia untuk `Reporter`, `Admin`, `Satgas PPKS`, dan `Super Admin`.
- Email/notifikasi dapat diverifikasi melalui UI, database test, mail catcher, atau mekanisme QA yang tersedia di environment.
- Data sensitif yang digunakan dalam pengujian harus berupa data dummy.

## Exit Criteria

- Semua test `High` lulus atau memiliki bug terdokumentasi dengan severity/status yang jelas.
- Tidak ada runtime crash pada alur reporter, admin, satgas, dan super admin.
- Role-based access sudah diverifikasi dari UI dan, untuk aksi kritis, backend menolak akses tidak sah.
- Mobile, dark mode/light mode, dan lokalisasi Bahasa Indonesia/English sudah lolos smoke test.
- Semua bug hasil eksekusi manual dicatat di `docs/BUG_REPORT.md` sesuai status yang diizinkan: `Open`, `In Progress`, `Resolved`, `Verified`, atau `Closed`.
