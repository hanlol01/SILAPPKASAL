# SILAPPKASAL

Sistem Informasi Laporan Pencegahan dan Penanganan Kekerasan Seksual.

## Repository Structure

- `docs/` - Project documentation for Phase 1-4.
- `frontend/` - React Lovable/TanStack Start web frontend.
- `backend/api/` - Laravel REST API target folder for the next milestone.
- `mobile/` - Placeholder for the future Flutter mobile app.
- `equity-watch-app/` - Temporary backup of the previous project folder. Do not delete until reviewed.

## Frontend Setup

```powershell
cd frontend
npm install
npm run dev
```

Default API URL is configured in `frontend/.env.example`:

```env
VITE_API_URL=http://localhost:8000/api/v1
```

## Backend Setup

Laravel is not installed in Milestone 1. The backend will be scaffolded later in `backend/api/` during Milestone 2.
